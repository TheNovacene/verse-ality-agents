# Contributing
We welcome contributions aligned with our **Ethics & Consent**.

## Process
1. Fork + create a feature branch.
2. Ensure all code files include `SPDX-License-Identifier: AGPL-3.0-only`.
3. Run tests and linters; add/expand docs.
4. Confirm you've read **ETHICS.md**, **AUP.md** (if present), and the Verse-ality Brand Guide.
5. In your PR, paste the contributor sign-off line:
   `I have read and agree to assign my contribution to The Novacene Ltd under the project's open-source (AGPL-3.0-only) and commercial licences.`

## PR Checklist
- [ ] Ethics checked (relational integrity honoured; no hidden data flows)
- [ ] Unit tests & docs updated
- [ ] No private data in fixtures
- [ ] Glyph and brand usage compliant
- [ ] SPDX header present on all new code files
